# HP t730 Lab — sanitized project photos

This folder contains publication-safe copies of hardware images and a cropped GitHub screenshot.

Edits: Opaque masks were applied over identifiable device serial numbers,
MAC addresses, barcodes, QR codes, inventory labels, and ID-bearing component stickers.
The browser screenshot was cropped to remove browser chrome and personal bookmarks.

The exported images were freshly encoded without original EXIF/GPS metadata.

Use ONLY these files for the public repository. Retain originals privately.
For future screenshots, remove local/public IP addresses, device hostnames,
email addresses, network credentials, and authentication tokens before uploading.
